## Reporting a Vulnerability

If you discover a security vulnerability in TECHNEWS, please report it privately by opening an issue labeled `security` or contacting the maintainer directly.

Preferred disclosure steps:

1. Provide a clear description and steps to reproduce.
2. Include the affected version and any relevant logs.
3. Do not publish the vulnerability publicly until a fix is available.

## Supported Versions

This repository uses Laravel 10 and PHP 8.1+. Security fixes will be applied to supported branches.

## Security Best Practices

- Rotate credentials regularly.
- Do not commit private keys or secrets to the repository.
- Use environment variables for secrets and keep `.env` out of source control.
